# Fonte self-hosted

`inter-latin-variable.woff2` é o subset latino da Inter Variable, copiado sem
alteração de `@fontsource-variable/inter@5.3.0` (`files/inter-latin-wght-normal.woff2`).

Servir a fonte do próprio domínio evita requisições a terceiros, remove um
render-blocking externo e mantém a tipografia correta com o app instalado offline.

Inter é distribuída sob a SIL Open Font License 1.1.
